# 🌾 Crop Yield Prediction using Machine Learning

An interactive **Streamlit-based web application** that predicts crop yield using machine learning techniques based on agricultural and environmental parameters such as rainfall, temperature, soil type, fertilizer usage, irrigation, and weather conditions.

---

## 📌 Project Overview

Agriculture is a backbone of the economy and plays a critical role in ensuring food security. Accurate crop yield prediction is challenging due to the involvement of multiple environmental and agricultural factors.

This project applies **Machine Learning** techniques to predict crop yield and deploys the trained model using **Streamlit**, enabling real-time predictions, data visualization, and performance analysis through a user-friendly web interface.

---

## 🚀 Features

- 🔮 **Crop Yield Prediction**
  - Predicts crop yield (tons/hectare) based on user inputs.
- 📊 **Exploratory Data Analysis (EDA)**
  - Visual insights using histograms, scatter plots, and box plots.
- 📈 **Model Performance Evaluation**
  - Displays key metrics such as MAE, RMSE, and R² Score.
- 🎨 **Interactive UI**
  - Clean and responsive Streamlit interface with sidebar filters.

## 📂 Dataset Description

The dataset contains agricultural and environmental features including:<a href="https://www.kaggle.com/datasets/samuelotiattakorah/agriculture-crop-yield/data">Data Set</a>

- Crop
- Region
- Soil Type
- Rainfall (mm)
- Temperature (°C)
- Fertilizer Used
- Irrigation Used
- Weather Condition
- Yield (tons/hectare)

---

## ⚙️ Data Preprocessing Steps

- Data cleaning and formatting
- Handling missing and inconsistent values
- One-Hot Encoding for categorical variables
- Feature scaling using StandardScaler
- Train-test split (80% training, 20% testing)

## 📊 Model Performance Metrics

- **Mean Absolute Error (MAE):** Low average prediction error  
- **Root Mean Squared Error (RMSE):** High prediction accuracy  
- **R² Score:** Indicates excellent model fit  
- **Dataset Size:** 1,000,000 records
